📝 Modern Contact Form — Angular 18 Challenge
A high-performance, fully validated contact form built with Angular 18. This project showcases advanced Reactive Forms implementation, complex custom validation logic, and modern reactive state management using Signals.

✨ Features
📱 Fully Responsive UI: Built with Tailwind CSS, optimized for a seamless experience across Mobile, Tablet, and Desktop.

🧪 Advanced Reactive Forms: Implements FormGroup and FormControl with real-time validation feedback and conditional logic.

🛠️ Custom Group Validators: Features sophisticated cross-field validation (e.g., ensuring at least one query type is selected using atleastOneChoice).

⚡ Angular Signals: Leverages the latest reactive primitives for efficient component state handling and clean data flow.

🎨 Custom Interactive UI: Bespoke checkboxes and radio buttons styled with Tailwind, featuring smooth hover transitions and active states.

✅ Optimized UX: Intelligent error handling using markAllAsTouched() to trigger validation alerts immediately upon submission.

🔧 Technologies Used
Angular 18 (Standalone Components, Signals, New Control Flow @if/@else)

Reactive Forms API (Form building, complex validation, and status tracking)

Tailwind CSS (Utility-first styling, custom HSL palettes, and ring utilities)

TypeScript (Strict typing for robust form data handling and business logic)

HTML5 & Semantic UI (Accessible structure and clean template logic)

📂 Architecture & Best Practices
The project follows a Standalone Architecture, eliminating unnecessary modules for faster bundle sizes and cleaner code. Complex styling logic is moved into TypeScript Getters, ensuring the HTML templates remain declarative, readable, and easy to maintain.
