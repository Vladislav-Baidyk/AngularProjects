# Social Links Profile — Modern Angular Challenge

A high-performance, sleek social links profile card built with **Angular 18**. This project demonstrates modern frontend practices, including standalone components, reactive signals, and utility-first styling.

---

## ✨ Features

* 📱 **Fully Responsive:** Adaptive UI built with **Tailwind CSS**, perfectly optimized for mobile, tablet, and desktop.
* 🧩 **Standalone Architecture:** Modern Angular structure without unnecessary modules for faster loading and cleaner code.
* ⚡ **Angular Signals:** Implements the latest reactive primitive for efficient state management.
* 🎨 **Professional UI:** Features custom HSL color palettes, Google Fonts integration (Inter), and smooth hover transitions.
* 📂 **Component-Driven:** Modular design with reusable logic (e.g., dynamic link lists).

---

## 🔧 Technologies Used

* **Angular 18** (Standalone Components, Signals, `imports` array)
* **Tailwind CSS** (Utility-first styling, custom arbitrary values like `w-[20%]`)
* **TypeScript** (Strict typing for robust data handling and component logic)
* **Google Fonts** (Integrated 'Inter' font for premium typography)
* **HTML5 & CSS3** (Semantic layout and custom CSS variables)
